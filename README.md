# RecorridoVirtual

- Punto de partida, lo que ya había construido
No empecé desde cero. Mi primera página web, ElNolugardeLau, se convirtió en la base de este nuevo proyecto. De allí copié los assets y, sobre todo, intenté entender cómo funcionaba, cómo estaba armada, qué hacía cada parte y por qué se veía como se veía.
Copié el HTML y el CSS y los traslapé a la nueva página. Fue una forma de aprender haciendo.

- Animaciones y colores, el primer tropiezo
Una vez tuve la estructura, volví a poner las animaciones. Ese paso fluyó relativamente bien, porque ya las había trabajado antes.
El primer obstáculo real llegó con los colores. Quería cambiarlos y no entendía muy bien cómo hacerlo, no sabía en qué parte del código se definían ni cómo modificarlos sin romper lo demás. Me tomó un tiempo, pero esa frustración fue también el comienzo de una comprensión más profunda del CSS.

- El recorrido, cuando le cogí el tiro
Después de esa primera dificultad, algo hizo clic. Le cogí el tiro al manejo de los colores y luego pude construir seis páginas para el recorrido. Cada una se volvió una estación dentro de la experiencia que quería proponer a quien visitara el sitio.

- La música, buscar respuestas por mi cuenta
Quería que la página tuviera música, que el recorrido no fuera solo visual sino también sonoro. Pero no sabía cómo incorporarla. En lugar de quedarme ahí, busqué en GitHub cómo hacerlo y a partir de lo que encontré, logré integrarla. Ese momento me mostró que parte del proceso creativo también es saber buscar y aprender de lo que otras personas ya resolvieron.

- El texto, un artículo que por fin encontró su lugar
Para el contenido retomé un artículo que había escrito y que nunca publiqué en Substack. Era sobre el recorrido por las cárceles que conocí y siempre había querido darle una salida. La página web se convirtió en ese espacio.
Articulé los párrafos dentro de la estructura del sitio. La parte más dispendiosa fue que el proceso es muy manual, pues hay que separar el texto párrafo por párrafo para ubicarlo en el código. Es un trabajo lento.

- Color, imágenes y publicación, lo que todavía me cuesta
Con el texto en su lugar, le puse colores y busqué imágenes para acompañarlo. Aquí noto que todavía no soy muy ágil, ya que me cuesta organizar las imágenes, ubicarlas y hacer que dialoguen con el texto.
También me pasa que a veces olvido cómo se publica una página. Es un paso que no hago con tanta frecuencia y cuando llega el momento, tengo que volver a recordarlo.

- Lo que aprendí
Con el tiempo fui entendiendo cómo funciona el sistema de HTML y CSS. Lo que al principio era copiar y pegar se convirtió, poco a poco, en una comprensión de por qué las cosas se ven y se comportan como lo hacen.
Este proceso me dejó la certeza de que aprender a construir una página web no es un camino lineal.
